# Database Migrations and Table Ownership

This document provides a comprehensive operational reference for all database tables in Accensa, detailing each table's owning service, primary functional responsibility, and source of truth for schema provisioning.

## Provisioning Architecture

Accensa provisions database schemas through two complementary mechanisms:

1. **SQL Migration Files (`migrations/*.sql`)**: Applied sequentially to production and test PostgreSQL instances to establish relational structure, constraints, and indexes.
2. **In-Code Schema Guards (`apps/web/src/lib/db.ts` and domain modules)**: Idempotent `CREATE TABLE IF NOT EXISTS` clauses executed during bootstrap via `ensureSchema()` to support ephemeral testing and self-healing local developer environments.

Where a table is provisioned both in a migration file and in code, the migration file defines the canonical schema, and the code mirrors it for runtime resilience.
